# CSES education field-wave profiles

Companion to the [education brief](cses-education-alignment.md). All counts are member-wave records, not directly interviewed people. The literal-route counts combine the printed age threshold with observed Yes gates; they are diagnostic denominators, not an adopted estimator. Missing forms receive no borrowed age/route denominator. The absent 2004 years-attended item receives no invented route denominator. Detailed source-code non-null counts can include unknown codes; consult the harmonized field and literal option evidence before treating them as substantive answers.
