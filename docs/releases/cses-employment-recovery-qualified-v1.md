# EC recovery and interpretation interface v1

Published to `mda` on 2026-09-06 after the user approved continuing with the three reviewed
corrections. The release adds one versioned auxiliary table and two security-barrier views in
the existing `cses_analysis` schema. The committed state passed independent forced read-only
validation and reproducible graph export.

Use the [corrected EC interface](../cses-employment-corrected-interface.md) for the new values and
qualifications. The original physical EC table, its `public` compatibility view and the earlier
age-only EC view remain unchanged. No interface is silently redirected.

## Published objects

| Object in `cses_analysis` | Rows | Columns | Purpose |
| --- | ---: | ---: | --- |
| `cses_ec_aligned_v1` | 332,903 | 74 | Age-qualified EC with recovered days and missing/top-code interpretation |
| `cses_ec_secondary_days_recovery_v1` | 13,830 | 4 | Same-wave original 2009 day values and source-row identities |
| `cses_ec_correction_rule_v1` | 4 | 17 | Source-variable, file/hash, questionnaire and interpretation provenance |

The auxiliary table is a new physical analysis-support relation, bringing the CSES physical-relation
count from 35 to 36. All 35 pre-existing relations, their values, prior view definitions, permissions
and indexes remain unchanged. The historical 22-entry storage registry, variable/question catalog,
alignment releases and load-run records remain unchanged. The auxiliary table is tracked through
this versioned interface's rule view, exact execution evidence and graph, not misrepresented as an
additional historical registered core relation. No new schema or eighth core table was created.

## Exact effect

| Rule | Source variable ID | Effect |
| --- | ---: | --- |
| Recover 2009 `q15_c17` | 989 | Fill 13,830 NULL secondary-days values in the new view only |
| Interpret 2004 `q13b06_1` | 344 | Expose NULL for 185 labelled-missing main-job status cells in a separate interpreted field |
| Interpret 2004 `q13b06_2` | 345 | Expose NULL for 71 labelled-missing secondary-job status cells in a separate interpreted field |
| Qualify 2004 `q13a05` | 306 | Six total-hours values become explicitly 96+, with lower bound 96 and exact hours NULL |

Original employment-status codes and hours remain present. The 256 status cells are not a count of
distinct respondents. The new view retains every row and both unmatched HL records. All three
existing age-96+ qualifications are preserved independently of weekly-hours topcoding. No values
from other waves are borrowed and no non-null secondary-days value is overwritten.

Matching versioned [EC Parquet](../../data/processing/cses/employment_corrected_v1/final_EC_CSES.parquet)
and [recovery Parquet](../../data/processing/cses/employment_corrected_v1/secondary_days_recovery.parquet)
are stored separately from the frozen baseline. Local/database archive-path differences are
normalized for comparison only, not rewritten in the database.
